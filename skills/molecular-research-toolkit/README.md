# Molecular Research Toolkit · package entry

[Installation](INSTALL.md) · [Agent instructions](SKILL.md) · [Table contract](references/table-contract.md)

This is an early development bundle. Check the installation guide's platform coverage
and review all scientific outputs before reuse.

This folder supplies setup guidance and small table/file operations. The three complete
skills are alongside it under `../modules/` in the download and remain directly callable.
Use the generic directory installer to make all four entries discoverable; your agent
chooses the appropriate directory and checks discovery afterward.

You can ask to create a table, fill reviewed SMILES and InChIKey, organize paper data,
or export specified reviewed IDs without running the whole workflow. The full project
also distributes [Barkla tools separately](https://github.com/BanchaoRuan/molecular-research-toolkit/tree/main/tools/barkla_redox).
