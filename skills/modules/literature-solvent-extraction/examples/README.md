# example001

**example001 · Michler's ketone** demonstrates a supported extraction and the complete review package. Follow the [walkthrough](example001/README.md) to trace oxidation and reduction separately, distinguish electrochemical and photophysical solvents, and check the evidence before accepting the result.

| File | Purpose |
| --- | --- |
| [Input workbook](example001/input/example001.xlsx) | Start with blank manual and AI-assisted solvent cells. |
| [Filled workbook](example001/output/example001.xlsx) | Compare your result with the supported output. |
| [Excel review](example001/output/review/solvent_review.xlsx) | Check assessments, reference URLs and tested search terms. |
| [Evidence images](example001/output/review/evidence/) | Follow the six images in reading order. |

The example starts from Table 1 of [Wu, Kim and Teets](https://doi.org/10.1055/a-1390-9065). Its input preserves the `Fixed` and `Data from Paper` layout.

After [installing the skill bundle](../README.md#1-install-the-skill-bundle), save a working copy of the input workbook in your task project, attach it to the chat, supply the starting paper, and use the [activation prompt](../PROMPTS.md). The submitted working copy remains untouched; the agent delivers a new solvent-stage copy. The packaged input and output remain available for comparison and repeat runs.
